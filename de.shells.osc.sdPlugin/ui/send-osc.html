About argument types

Integer, float, string and blob are the four types every OSC device is required to understand. The others are optional in the specification — a device is allowed to ignore a message that uses one. If a message has no effect, try expressing it with the required types first.

True, false, nil, infinitum and the array brackets carry no value; they occupy a slot in the type tag string only.

About receiving values

OSC has no request and response: nothing comes back because you sent something. Your device has to be configured to transmit to this computer's IP address, on the port set above. The first time the plugin listens, your firewall will most likely ask permission.

Some equipment stays silent until it is asked to report. A Behringer X32, for example, sends nothing until it receives /xremote, and stops again after about ten seconds — that is what the keep-alive is for. Unity, Unreal and TouchOSC need nothing; they transmit as soon as you configure them to.
